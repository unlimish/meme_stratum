# ロータリーエンコーダー筐体（3Dプリント用）

Meme Stratum 展示用コントローラー（ロータリーエンコーダー + Pico W）を収める
円筒2ピース構成のパラメトリック筐体。OpenSCAD 2021.01 で作成。

```
hardware/case/
├── encoder-case.scad        ← 本体（パラメトリック、body/lid/assembly を1ファイルで管理）
├── encoder-case-body.stl    ← 印刷用（受け皿側）
├── encoder-case-lid.stl     ← 印刷用（蓋側）
├── preview-assembly.png     ← 組み立てプレビュー（ノブのゴースト付き）
├── preview-body.png
├── preview-lid.png
└── README.md                ← このファイル
```

## 筐体の構成

- **body（受け皿）**: φ110、側壁3mm、床3mm、外形高さ52mm。内側の床にハーフサイズ
  ブレッドボード位置決めポケット（4隅L字リブ）、側面にmicro USBケーブル引き出し用の角丸ポート、
  ポート内側に結束バンド用の穴2つ、蓋固定用のM3ネジボス3本（120°等配、ケーブルポートを
  避けて60/180/300°に配置）。
- **lid（蓋）**: φ110、パネル厚3mm＋位置決めリップ2mm。中心にエンコーダーのブッシュ通し穴
  （φ9.2）、回り止めタブ用の角穴、皿もみ済みM3通し穴3箇所。
- 組み立て後の総高さ：約55mm（body 52mm + lidパネル3mm、リップはbody内部に収まる）。

### 寸法チェック（`.scad` の echo で自動出力される値）

- body内径 = 104mm（φ110 − 側壁3mm×2）
- ブレッドボード対角線 = 99.6mm → 内径104mmで確保
- ポケット対角線（クリアランス込み）= 101.0mm、内径との余裕 = 3.0mm
- 内部の使用可能高さ（床上面〜リム上端）= 49mm
  → ブレッドボード10mm + Pico Wピンヘッダ込み実効高さ12mm = 22mm の積み上げに対し
     十分な余裕（中央部でリップの干渉なし）
- 総高さ 55mm ≤ 上限60mm

`openscad` 実行時に上記が標準出力にechoされるので、パラメータ変更後は必ず確認すること。

### 重要：エンコーダー本体とPico Wの位置関係について

エンコーダーのブッシュ穴・回り止めタブは蓋の**中心**にあり、ブレッドボードの位置決め
ポケットも床の中心に配置されている（丸い筐体なので中心以外に置けない）。つまり
エンコーダー本体・はんだラグ・配線は筐体の中心付近から下に垂れる形になる。

**→ Pico W はブレッドボードの中央ではなく、片端（USBコネクタが側面ケーブルポート側を
向く向き）に挿すこと。** ブレッドボード中央付近はジャンパー線だけが通るようにし、
Pico W本体をエンコーダーの真下から外すことで干渉を避ける。

## 印刷設定（推奨）

- レイヤー高さ: 0.2mm
- インフィル: 15〜25%
- 材料: PETG または PLA
- サポート: 不要（両パーツともサポートレス設計）
- 印刷向き:
  - **body**: 開口部を上にして印刷（底面が積層開始面）
  - **lid**: 見せ面（ノブ側＝パネル上面）を下にして印刷
    （`encoder-case-lid.stl` は出力時にあらかじめ180°反転済みなので、
    スライサー上で追加の回転操作は不要。皿もみ穴がベッド側になるため
    サポート無しできれいな皿もみ面が得られる）
- body底面外周には印刷ベッドのエレファントフット対策の面取り（0.6mm）を追加済み

## 組み立て手順

1. bodyの床のポケットにハーフサイズブレッドボードを落とし込む（粘着シールは任意）。
   USBコネクタ側がケーブルポート側を向くよう、ブレッドボードの長辺をポートの軸に合わせる。
2. Pico Wをブレッドボードの片端（ポート寄り、エンコーダー中心の真下を避けた位置）に挿す。
3. エンコーダー配線（A相→GP2、B相→GP3、COM→GND、SW→GP4+プルアップ）をはんだ付け。
4. micro USBケーブルをbody側面のケーブルポートから通し、Pico Wに接続。
5. ケーブルポート内側の結束バンド用の穴2つを使い、ケーブルを床に軽く固定（ストレイン
   リリーフ）。
6. エンコーダーを蓋のブッシュ穴に通し、回り止めタブをタブスロットに合わせて挿入、
   付属ナットで固定。
7. 蓋をbody上端リップに合わせて被せ、M3皿頭タッピングビス3本（蓋側の皿もみ穴 →
   body側のボス下穴）で固定。
8. エンコーダーのシャフトにメタルノブ（K-29-6.1）を被せ、イモネジで固定（六角レンチ1.5mm）。

## 実測して調整すべきパラメータ（印刷前に必ず確認）

`encoder-case.scad` 冒頭のパラメータ部に `★実測して調整★` と明記している。特に以下は
実機のエンコーダーをノギスで測ってから最終出力すること。

| パラメータ | 現在値 | 内容 |
|-----------|-------|------|
| `BB_W` / `BB_D` | 83mm / 55mm | ブレッドボード外形。400穴はメーカーで81〜84×54〜56mmと差があるため実測必須 |
| `BUSHING_HOLE_D` | 9.2mm | エンコーダーのブッシュ（ねじ部）外径に対する通し穴。公称φ9mm＋クリアランスの概算値 |
| `TAB_SLOT_OFFSET` | 7.5mm | パネル中心から回り止めタブ中心までの距離 |
| `TAB_SLOT_W` / `TAB_SLOT_H` | 3.2mm / 2.2mm | タブスロットの幅・高さ |
| `TAB_SLOT_ANGLE` | 90° | ケーブルポート方向（0°）を基準としたタブの角度位置 |

タブが既に折れている、またはタブ無しの個体の場合は `TAB_SLOT_ENABLE = false` にして
再出力すれば、タブスロットの無い丸穴のみの蓋になる。

## STLの再出力方法

パラメータを変更したら、リポジトリルートから以下を実行して再生成する
（`hardware/case/` に `cd` して実行してもよい）。

```bash
cd hardware/case

# 事前チェック（CGALの警告・非manifold形状が出ないか確認、/dev/nullに書き捨て）
openscad -o /dev/null -D 'PART="body"' encoder-case.scad
openscad -o /dev/null -D 'PART="lid"'  encoder-case.scad

# STL本出力
openscad -o encoder-case-body.stl -D 'PART="body"' encoder-case.scad
openscad -o encoder-case-lid.stl  -D 'PART="lid"'  encoder-case.scad

# プレビュー画像の再生成（X無しの環境では xvfb-run を使う）
xvfb-run -a openscad -o preview-body.png     --imgsize=1200,900 --render \
  --colorscheme="Tomorrow Night" --camera=0,0,26,60,0,25,170 --projection=o \
  -D 'PART="body"' encoder-case.scad
xvfb-run -a openscad -o preview-lid.png      --imgsize=1200,900 --render \
  --colorscheme="Tomorrow Night" --camera=0,0,2.5,55,0,25,140 --projection=o \
  -D 'PART="lid"' encoder-case.scad
xvfb-run -a openscad -o preview-assembly.png --imgsize=1200,900 \
  --colorscheme="Tomorrow Night" --camera=0,0,43,65,0,25,240 --projection=o \
  -D 'PART="assembly"' encoder-case.scad
```

`openscad` （プレビューGUI）で `encoder-case.scad` を直接開き、上部の `PART` を
`"assembly"` にしてF5プレビューすると、ノブ・ブレッドボード・Pico Wのゴースト表示付きで
組み立て状態を確認できる（STL出力には影響しない）。
