# Meme Stratum

静的ホスト用ビルド済みファイルは `dist/` に含まれています。

## 公開URL

- GitHub Pages: `https://unlimish.github.io/meme_stratum/`
- Cloudflare Pages: （任意のブランチ・connect後）

## 展示機での起動

`exhibit/start-nodeless.command` をダブルクリック。
詳細は `exhibit/EXHIBIT.md` 参照。

## 開発

```bash
npm install
npm run dev
npm run build
```

`dist/` は既にリポジトリに含まれているので、展示機では Node/npm 不要。
